## Overview

StaySync by Integrivo is a product-facing website presenting a unified approach to short-term rental property management. Its pages explain capabilities and communicate the value of connecting operational tasks in one place.

## What the project includes

- Marketing sections for dashboard, channel-sync, automation, and reporting concepts.
- Separate feature, pricing, and contact pages.
- Motion-led presentation and responsive product messaging.

## Technical approach

The repository is a Next.js frontend with Tailwind CSS, Framer Motion, and Lucide icons. The website illustrates integrations and automation concepts through its interface and copy.

## Scope and status

This repository is the marketing/product website, not proof that every advertised channel integration is already operational. The description intentionally distinguishes the promotional experience from the wider application platform.
