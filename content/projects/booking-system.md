## Overview

This repository combines a fitness-focused React frontend and a NestJS API. Its structure covers the experience of discovering trainers and working with structured coaching and exercise programs.

## What the project includes

- Trainer and coach profiles, qualifications, and expertise areas.
- Fitness programs, workout templates, exercises, and workout-completion modules.
- Member account flows and coaching packages, with related backend endpoints.

## Technical approach

A NestJS server provides authentication and domain modules for coaching, users, programs, and packages. PostgreSQL and TypeORM support persistence, while the client uses React and Vite with component libraries for dashboards and forms.

The repository contains interfaces and domain services for a fitness coaching workflow. No deployment URL or verified usage metrics are provided.
