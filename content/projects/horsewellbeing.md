## Overview

HorseWellBeing is an early-stage mobile UI repository. Its current emphasis is on an initial localized onboarding experience rather than a complete application workflow.

## What the project includes

- Expo Router project structure for a mobile-first React Native application.
- A language-selection screen for Arabic and French, using locally bundled imagery and flags.
- NativeWind styling and a simple gradient-based selection treatment.

## Technical approach

The codebase uses Expo, React Native, TypeScript, and NativeWind. The language-selection component exists in the repository; the root screen currently does not render a complete product experience.

## Scope and status

**Prototype status:** The main application is not yet feature-complete. This entry is deliberately labeled a UI prototype to avoid implying a finished equine-health service.
